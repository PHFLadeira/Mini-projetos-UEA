Como usar o ECA Flow
Sistema integrado de Grade + Horários

🗺 1. Grade Curricular

Marque as matérias já concluídas, em curso e reprovadas importando seu histórico PDF. O sistema detecta automaticamente quais matérias você pode cursar no próximo semestre com base nos pré-requisitos.

📅 2. Montador de Horários

Carregue os PDFs de horário acadêmico. As matérias que você pode cursar aparecem na barra lateral esquerda. Clique nelas para adicioná-las ou use "Montar automaticamente" para criar uma grade sem conflitos.

⚡ 3. Montagem Automática

O botão ⚡ monta a grade respeitando a aba Filtros (turno, dias, CH máx.) e a aba Prioridade: matérias de prioridade Alta entram primeiro, depois as de período mais baixo, sempre evitando conflitos. Você ainda pode ajustar manualmente depois.

📋 4. Resultados

Veja a grade visual semanal, a lista completa de matérias e os conflitos. Exporte como imagem PNG para compartilhar com colegas.

💾 Dados salvos automaticamente. Seus dados ficam no navegador — 100% privado, nada é enviado para servidores. Use Backup (aba Grade Curricular) para salvar um arquivo e levar para outro dispositivo.
